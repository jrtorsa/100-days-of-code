The Machine Learning Lifecycle

You now know what ML is and how it learns. This lesson closes out Domain 1: the stages a model goes through from raw data to a working prediction in production — and why it doesn't stop there.

1. Data collection & preparation
Gather relevant data and clean it up (missing values, duplicates, inconsistent formats). Garbage in, garbage out — this stage usually takes the most effort.
2. Model training
The algorithm looks at the training data and adjusts itself to capture the pattern in it.
3. Evaluation
Test the trained model on data it has never seen, to see if it actually generalizes or just memorized the training set.
4. Deployment
The model goes live, making real predictions on real, incoming data.
5. Monitoring
Keep watching accuracy over time. Real-world data shifts — that's called drift — and a model that was accurate at launch can quietly get worse. Monitoring is what catches that, and feeds back into stage 1.

It's a loop, not a line: see the full diagram in the reference sheet.

Why this matters for the exam: expect questions that describe a stage ("the team tests the model on a holdout set it never trained on") and ask you to name it, or that ask why a deployed model's accuracy dropped months later (answer: drift → needs monitoring/retraining).
