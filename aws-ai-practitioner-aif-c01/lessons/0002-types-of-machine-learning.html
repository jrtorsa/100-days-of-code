Types of Machine Learning

In Lesson 1 you learned that ML learns patterns from data instead of hand-coded rules. Today's question: what kind of data, and what kind of "learning," exactly? There are three answers, and the exam constantly tests whether you can tell them apart from a short scenario.

Supervised learning
You give the model labeled data: inputs paired with the correct answer. It learns to predict the label for new, unseen inputs.
Example: training on emails already marked "spam" / "not spam" to classify new emails.
Unsupervised learning
You give the model data with no labels. It finds structure or groupings on its own — nobody told it what the "right" grouping was.
Example: grouping customers into segments based on purchase behavior, without predefined segment names.
Reinforcement learning
There's no fixed dataset at all. An agent takes actions in an environment and gets a reward or penalty, and learns a strategy that maximizes reward over time.
Example: AWS DeepRacer learning to drive a track faster by being rewarded for staying on the track.

Full comparison table (data needed, goal, example) is saved as a standalone reference — see below.

Why this matters for the exam: a typical question describes a scenario ("a model recommends products based on browsing history with no predefined categories...") and asks which type of learning it is. You won't be asked to name algorithms — just to recognize the pattern: labeled answers, no labels, or a reward signal.

Practice with exam-style scenarios

1. A grocery chain wants to group its customers into segments based on purchase history, but has no predefined list of segment names for the model to target. Which type of machine learning best fits this use case?
No labels were ever provided — the model has to discover the groupings itself, which is exactly what unsupervised learning does.
2. A robotics team is training a warehouse robot to navigate around obstacles by giving it a small reward each time it avoids a collision and a penalty each time it hits something. Which type of machine learning best fits this use case?
A reward-and-penalty signal with no fixed labeled dataset is the defining trait of reinforcement learning.
3. A bank has ten years of loan applications, each already marked "approved" or "denied," and wants a model that predicts the outcome for new applications. Which type of machine learning best fits this use case?
Every past example already comes with the correct answer attached ("approved"/"denied") — that's a labeled dataset, the hallmark of supervised learning.
