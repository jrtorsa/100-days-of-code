AWS Infrastructure for Generative AI

Lessons 4–6 covered the concepts. This lesson closes Domain 2 with the concrete answer to "okay, so how do I actually use this on AWS?" Four names to know, each solving a different problem.

Amazon Bedrock
A fully managed service that gives you API access to several foundation models (Anthropic's Claude, Amazon's own Nova/Titan, Meta's Llama, Mistral, and others) through one consistent API — no servers to manage, no model to host yourself. This is the default answer whenever a question just says "build a generative AI application."
Amazon Q
AWS's own ready-made GenAI assistant, in two flavors: Amazon Q Business (a workplace assistant that answers questions using your company's own documents and data) and Amazon Q Developer (a coding assistant that suggests code and flags security issues inside your IDE).
PartyRock
A free, no-code playground built on top of Bedrock. Drag-and-drop your way to a working GenAI app to test an idea, with zero coding required.
Amazon SageMaker
The full ML toolkit from Lessons 1–3, now including SageMaker JumpStart, which offers pre-trained foundation models you can fine-tune and fully control — for teams that need more customization than Bedrock's managed API gives them.

How to pick, in one line each

No code, just want to try an idea → PartyRock. Need API access to foundation models without managing infrastructure → Bedrock. Want a ready-made assistant for work questions or coding → Amazon Q. Need to fully control training, fine-tuning, and deployment of a custom model → SageMaker.

The jargon, defined

Managed service
AWS runs and scales the underlying infrastructure for you — you call an API, you don't provision or patch servers.
Bedrock Agent
A Bedrock feature that lets a foundation model break a task into steps and call other APIs/tools to complete it, instead of just returning text.
Guardrails
Bedrock's configurable filters that block certain topics, harmful content, or PII in a model's input or output — a technical control for the responsible-AI risks from Lesson 5.
Why this matters for the exam: AIF-C01 loves to name a need (no-code prototype, coding help, full model control, managed API access) and ask which AWS service matches — exactly what the quiz below practices.

Practice with exam-style scenarios

1. A developer wants to call several different foundation models through one consistent API, without provisioning or managing any servers. Which service fits best?
One managed API for multiple foundation models, with no infrastructure to run, is exactly what Bedrock provides.
2. A software team wants an assistant built into their IDE that suggests code and flags security vulnerabilities as they type. Which service fits best?
Coding-specific help inside an IDE, including security scanning, is Amazon Q Developer's job specifically (Q Business targets workplace document Q&A instead).
3. A product manager with no coding background wants to quickly prototype a simple generative AI app idea to demo to the team. Which tool fits best?
No-code, fast prototyping of a GenAI idea is exactly what PartyRock is built for.
4. A company wants to fine-tune a foundation model on its own proprietary data and fully control the training and deployment infrastructure. Which service fits best?
Full control over fine-tuning, training, and deployment infrastructure is SageMaker's territory — Bedrock trades some of that control for a simpler managed API.
