Quick reference

AWS Generative AI services

Four names, four different jobs — read the need, not just the buzzword.

Service Best for Key trait
Amazon Bedrock Building an app on top of foundation models One managed API, multiple model providers
Amazon Q Ready-made assistant (work Q&A or coding) Business = docs; Developer = IDE/code
PartyRock Fast, no-code prototyping Free, drag-and-drop, built on Bedrock
Amazon SageMaker Full control over training/fine-tuning JumpStart offers pre-trained models to customize
One-line filter: no code → PartyRock. Managed API access → Bedrock. Ready-made assistant → Amazon Q. Full custom control → SageMaker.
