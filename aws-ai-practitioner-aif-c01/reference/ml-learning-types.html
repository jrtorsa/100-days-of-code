The 3 types of Machine Learning

Use this to classify any exam scenario in seconds: read the setup, ask "is there a labeled answer, no labels at all, or a reward signal?"

Type Data it needs Goal Example
Supervised Labeled data (input + correct answer) Predict/classify new, unseen inputs Spam email detection
Unsupervised Unlabeled data Find hidden patterns or groupings Customer segmentation
Reinforcement No fixed dataset — a reward signal Learn a policy through trial and error AWS DeepRacer, game-playing agents
Fast filter: "Correct answers given up front" → supervised. "No answers, just find structure" → unsupervised. "Trial, error, and a reward" → reinforcement.

Click a scenario to reveal the type — try to answer before you click.

A streaming service groups movies by viewing patterns, with no predefined category names.
Unsupervised learning — no labels were given; the model found the grouping itself.
A driving simulator learns to stay in its lane, getting a penalty every time it drifts out.
Reinforcement learning — no fixed dataset, just a reward/penalty signal over time.
A hospital has thousands of past X-rays already labeled "pneumonia" or "no pneumonia."
Supervised learning — every example already comes with the correct answer attached.
