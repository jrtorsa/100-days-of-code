Quick reference

Generative AI vocabulary

The four ideas underneath almost every Domain 2 question.

Foundation model
A large model pre-trained on broad data, adaptable to many downstream tasks (writing, summarizing, translating, coding) instead of just one narrow job.
Token
A chunk of text (word, sub-word, or punctuation) — the actual unit a foundation model reads and generates, one at a time.
Prompt
The input text you give the model to steer what it generates next.
Probabilistic generation
The model picks each next token based on likelihood, not a fixed rule — so the same prompt can yield different wording on different runs.
One-line filter: "One reusable model for many tasks" → foundation model. "The unit the model reads/writes" → token. "What you type in" → prompt. "Why the answer varies" → probabilistic.
