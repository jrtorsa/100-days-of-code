Stage Question it answers
1. Data collection & preparation Do we have enough clean, relevant data?
2. Model training Can the algorithm find a pattern in the training data?
3. Evaluation Does it work on data it has never seen?
4. Deployment Is it now making real predictions in production?
5. Monitoring Is it still accurate as real-world data changes?
Key term: when real-world data shifts away from the training data and accuracy quietly drops, that's called drift. Monitoring exists to catch it.

The team holds back 20% of labeled data and never shows it to the model during training.
Evaluation — testing on unseen (holdout) data to catch overfitting before shipping.
The model scores 99% on training data but only 60% on brand-new data it has never seen.
Overfitting, caught at the Evaluation stage — it memorized specifics instead of the general pattern.
Six months after launch, accuracy has quietly dropped even though nobody touched the model's code.
Drift, caught at the Monitoring stage — the real world changed, not the model. This loops back to stage 1 for retraining.
