↳ Monitoring detects drift → loops back to stage 1

Stage Question it answers
1. Data collection & preparation Do we have enough clean, relevant data?
2. Model training Can the algorithm find a pattern in the training data?
3. Evaluation Does it work on data it has never seen?
4. Deployment Is it now making real predictions in production?
5. Monitoring Is it still accurate as real-world data changes?
Key term: when real-world data shifts away from the training data and accuracy quietly drops, that's called drift. Monitoring exists to catch it.
